## 技术栈

| 层次 | 选型 | 说明 |
|---|---|---|
| 前端 | Vue 3 + Vite + TypeScript | 组合式 API，类型约束 |
| 样式 | Tailwind CSS 4 | 原子化样式，统一设计令牌 |
| 组件库 | Naive UI | 主题可配置，TS 友好 |
| 状态 / 路由 | Pinia + Vue Router 4 | 登录态集中管理，路由守卫 |
| 图表 | ECharts | 票房与上座率统计 |
| 后端 | Spring Boot 3 + Java 17 | 分层架构，依赖注入 |
| 持久层 | MyBatis 3（XML Mapper） | SQL 与代码分离，便于审查 |
| 认证 | JWT + BCrypt | 无状态令牌，密码加盐哈希 |
| 接口文档 | springdoc-openapi | Swagger UI 自动生成 |
| 数据库 | MySQL 8.0（InnoDB / utf8mb4_0900_ai_ci） | 16 表 + 3 视图 + 4 触发器 + 2 存储过程 |

## 快速开始

### 1. 准备数据库

MySQL 8.0 已安装并启动（服务名 `MySQL80`），执行建库脚本：

```powershell
& "D:\mysql\MySQL Server 8.0\bin\mysql.exe" -u root -p `
  --default-character-set=utf8mb4 < database\cinema_booking.sql
```

> 脚本第一行会 `DROP DATABASE IF EXISTS cinema_booking`，重复执行会清空已有数据。

### 2. 数据过期怎么办

种子数据按执行当天生成未来 7 天的排片。如果放置几天后首页没有可买场次，不必重建库，执行刷新脚本：

```powershell
& "D:\mysql\MySQL Server 8.0\bin\mysql.exe" -u root -p `
  --default-character-set=utf8mb4 < database\refresh_demo.sql
```

该脚本会重置订单与评论，并重新生成未来 7 天的场次、6 笔覆盖各状态的样例订单。
